Audio Development Projects

Contribution: Solo project
Software Used: Unreal Engine, Bandlab



This module was split into two different projects; one project focused on creating a usable and effective audio synethesiser using audio altering techniques to produce interesting sounds. Some of these techniques which were experimented with were distortion, delays and reverb.

This project was made using Unreal Engine, specifically utilising the metasound feature with it, and the blueprint for the project showcased my understanding of creating oscillators, filters and more advanced techniques like reverb.


The other project that was being worked on alongside this was a mechanical implimentaion in a theoretical game which utilsed audio in some manner.

The gameplay of this project was inspired by games such as "Dead by Daylight" from Behaviour Interactive as the zones around the AI agent provide the same audible reactions as the "Terror Radius" system in "Dead by Daylight".
The audio layers were made by myself however the audio clips were from free, premade audio files found on Bandlab. I feel that this implimentation went well and showcased my concept very well. I could have improved this project by creating the audio myself instead of using premade sounds, but I do not think the inclusion of those sounds soured the experience that much.
