Game AI

Contribution: Solo project

Software Used: Visual Studio, Unity



This project was my experience with the basics of Game Artifical Intelligence. The framework was created in the Unity engine and I contributed the functionality to each of the pre-made scenes. The scenes fell into three catagories which were steering behaviours, pathfinding algorithms and decision making algorithms

My experience with this project was quite hit and miss; some aspects I took to relatively quickly such as steering behaviours and the concepts of force accumulation or pathfinding algorithms like Dijkstra and A*. However, other areas I struggled for weeks before figuring out; for the wander steering behaviour, it took around 3 weeks of on and off changes before I figured out the issues behind the behaviour.
