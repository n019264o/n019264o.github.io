Aliens vs Robots

Aliens vs Robots was the final project of my first year at Dudley College of Technology and was made to test our ability to create sprites and our creativity to implement extra features like powerups and hazards. This game was my first ever attempt at creating a game and all the sprites shown have been created by me.

This game was actually my first ever game I made till completion and the powerups were the primary focus for making the game interesting. This project wasn’t really a test of my programming skills as we didn’t get taught anything coding related at this point. However, all the artwork I made in this game came out well and this work was even chosen as one of the projects to represent the class in the open evening at the end of that year which was quite an honour.
