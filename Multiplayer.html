Multiplayer Project

Genre: Shoot em up
Contribution: Solo Project
Software Used: Visual Studio

This project was one of the first things I was given in my second year and was my first interaction with threading code and figuring out how to create a multiplayer experience. This was an interesting project with various new areas of programming that I never knew about until then. Threading was an intriguing yet consfusing idea and I would need to spend far more time using them before I would be confident.

This project didn't end in a great fashion however as there was an issue with my multithreading that was causing a race condition that I couldn't quite fix. Despite this, I still found this project fun and I would always love to try my hand at it again someday.
